**Data Types and Converting Types**

1. Python has several built-in data types:
   - int
   - float
   - string
   - Boolean
   - list
   - tuple
   - set
   - dictionary

2. Python is dynamically **typed**, so the type is determined at runtime.

3. We can **convert between compatible types using functions** such as:
   - `int()`
   - `float()`
   - `str()`
   - `bool()`
